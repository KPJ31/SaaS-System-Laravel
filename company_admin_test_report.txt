Bugs found
- A suspended Company Admin could potentially keep using an existing authenticated session because role middleware did not check user status.
- Company settings accepted loose timezone, currency, invoice prefix, and default project status values.
- Project request workflow allowed repeated or invalid state changes and duplicate conversion risk.
- Task status changes could jump directly to invalid states.
- Payment verification/rejection allowed repeated or invalid transitions and lacked transaction/audit consistency.
- Payment requests accepted a zero amount.
- Payment refund action did not validate the current payment state.
- Invoice filtering did not reject cross-company Client/Project filter IDs.
- Invoice numbers were not validated as unique within the current company during form validation.
- Invoice due date and paid amount validation were too loose.
- Invoice send/paid/cancel actions did not enforce status transitions consistently.
- Report, attendance, and work-session CSV exports did not sanitize formula-like values.
- Employee/project filters in reports, attendance, and work sessions were not always rejected when they belonged to another company.

Root causes
- Some controllers correctly scoped base queries but did not validate request-supplied filter IDs.
- Several workflow actions trusted status names without checking legal previous states.
- Finance forms validated database existence but needed company-specific relationship and calculation rules.
- CSV export writers used raw fputcsv values without spreadsheet formula protection.
- Active-account checks were enforced during login but not consistently for already-authenticated sessions.

Bugs fixed
- Added active-account enforcement to RoleMiddleware.
- Tightened Company Settings validation.
- Added project-request transition rules, conversion transaction, audit logging, and duplicate conversion blocking.
- Added task transition rules and company-scoped task filter validation.
- Added payment filter validation, positive amount validation, transition checks, transactions, and audit logs.
- Added invoice filter validation, unique company invoice number validation, due-date validation, paid-amount validation, transitions, transactions, and audit logs.
- Added CSV formula-injection protection to Company Admin reports, work-session exports, and attendance exports.
- Added company-scoped Employee/Project filter authorization in reports, work sessions, and attendance.
